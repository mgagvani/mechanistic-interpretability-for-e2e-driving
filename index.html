Conference/Journal 2023

Mechanistic Interpretability for End-to-End Self-Driving

Manav Gagvani1, Benjamin Namikas2, Sivamurugan Velmurugan2, Nysa Kumar2, Shrey Sharma2, Thomas Joseph Peterson2, Pratyush Mathur2, Hyunseo Chang2, Rohan Paleja2
Machine Learning @ Purdue
CoRL 2026
Paper Supplementary Code arXiv

Abstract

End-to-end (E2E) autonomous driving models achieve strong planning performance but remain largely opaque, limiting observability and trust. We apply mechanistic interpretability to E2E driving by training Sparse Autoencoders (SAEs) on the internal activations of a simple, single-camera end-to-end path planning model. Unsupervised clustering of SAE latents reveals interpretable structure aligned with route intent, vehicle speed, and braking behavior, recovering route intent with 98.3% accuracy without supervision. Through paired counterfactual image edits, we further show that specific SAE features are visually grounded and systematically respond to scene changes such as traffic light state and stop sign presence. Steering individual SAE latents produces predictable, monotonic changes in planner outputs including lateral displacement, curvature, and braking. Finally, we demonstrate a practical application of these representations: we build a lightweight adapter trained on SAE latents that reduces trajectory selection error by 3.44%, outperforming an equivalent adapter that omits SAE latents, confirming that the sparse representation captures useful information for interpretability.

Steering a driving policy by its sparse-autoencoder features

One real frame, one real planner. Move a slider and you are clamping a single latent in the model's residual stream, then re-running the trajectory decoder. Every path below is a forward pass that was actually computed — nothing is interpolated.

What the sliders actually do

The planner is a four-block transformer over features from a single forward-facing camera. A top-k sparse autoencoder (384 latents, k = 24) is fitted to the query token leaving the last block, which is the token the trajectory decoder reads. Because that block is the last one, an edit to the token feeds the decoder directly, and no image needs re-encoding.

Each slider sets one latent to α × act_max, where act_max is that latent's largest activation anywhere in the validation split. The edited code is pushed back through the decoder and the planner re-runs from the patched token — the same intervention used for the paper's control numbers. The drawn path is the chosen plan: the one of 50 proposals with the lowest predicted error, which is what the car would execute.

Steering a single SAE latent can reliably change planning outputs to turn left or right at varying magnitudes, showing that disentangled SAE features correspond to specific concepts.
